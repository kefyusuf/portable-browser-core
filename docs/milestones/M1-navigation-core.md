## Review evidence boundaries

- Core behavior: 30 golden TSV cases plus targeted negative and Unicode tests. CI runs these on three operating systems.
- Platform portability: `wasm32-unknown-unknown` **compilation only**. No WASM host/runtime or browser execution was exercised.
- URLs returned by the resolver are decisions, **not authorization** for DNS, redirects or outbound network access; those belong to a future host.
- The completed CodeRabbit review's only actionable CI security item has a verified remediation. This does not imply independent approval for all test fixtures, locked dependencies or future platform adapters.
- PR #1 and the latest exact-head checks are the operational evidence index; older test results must not be promoted to newer commits.
